# Inventario — instrucciones para agentes

Librería Python de gestión de inventario. Proyecto de práctica.

## Comandos
- Tests: `uv run pytest -q`
- No hay servidor ni base de datos.

## Convenciones
- Código y comentarios en español.
- Precios en euros como `float`, siempre redondeados a 2 decimales al devolverlos.
- Cualquier cambio de comportamiento lleva su test en `tests/`.
- No añadas dependencias sin preguntar.
